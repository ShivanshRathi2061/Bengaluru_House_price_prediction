# 🏠 Bengaluru House Price Predictor

A Machine Learning web application built using Streamlit that predicts Bengaluru house prices based on:

- 📍 Location
- 📐 Total Area (Square Feet)
- 🛏️ BHK
- 🚿 Bathrooms
- 🌇 Balconies

## Features
- Real-time house price prediction
- Price per square foot estimation
- Clean and responsive Streamlit interface
- Trained on 12,000+ Bengaluru housing records

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- NumPy
- Pandas
